# 2026-05-17 SSMK Content Intelligence v2 Handoff

작성일: 2026-05-17

이 문서는 다음 작업자가 오늘 논의한 SSMK 콘텐츠 품질 개선 방향을 빠짐없이 이어받기 위한 인수인계 문서다.

## 1. 이번 세션의 결론

이번 세션에서 확인한 핵심 결론은 다음과 같다.

```text
SSMK Weekly Lab의 현재 문제는 단순한 디자인 문제가 아니라,
콘텐츠를 생성하는 AI/Agent의 사고 수준이 아직 낮다는 문제다.
```

HTML에는 `실제 변화`, `해석`, `초보자 레슨`, `다음 확인 질문` 구조가 생겼고, `학습 사다리`, `시장 온도계`, `가설 복기 지도` 같은 시각 요소도 들어갔다.

그러나 최신 결과물을 검토한 결과, 여전히 아래 문제가 남았다.

- 상단 `숫자`, `의미`, `레슨`, `다음 확인` 박스가 본문을 잘라 붙인 중복 요약처럼 보인다.
- 말줄임표로 잘린 내용이 있어 독자에게 쓸모 있는 요약이 되지 못한다.
- 실제 변화 영역에서 종목과 숫자가 길게 나열되어 가독성이 낮다.
- 가격 변화는 표나 그래프 중심으로 보여줘야 한다.
- 해석과 초보자 레슨이 일반론에 머물러 실질적 인사이트가 약하다.
- 다음 확인 질문은 아직 "무엇을 보면 가설을 유지/수정할지"까지 충분히 가지 못한다.
- 콘텐츠가 미국 증시 구루가 초보자에게 설명하는 수준까지 올라오지 못했다.

## 3. 중요한 방향성

### 3-1. 템플릿 반복 금지

사용자는 "몇몇 템플릿이 반복되는 흔한 콘텐츠"가 되는 것을 강하게 경계했다.

따라서 다음 구현에서 중요한 것은 고정 문장을 많이 넣는 것이 아니다.

반복되어야 하는 것은 아래 사고 순서다.

```text
실제 데이터
-> 데이터 조합의 의미
-> 현실 흐름/시장 심리/사업 가설
-> 초보자 관찰법
-> 다음 검증 기준
```

반복되면 안 되는 것은 아래와 같은 문장이다.

```text
점수는 답이 아니라 질문입니다.
초보자는 숫자 하나를 외우기보다...
좋은 회사와 좋은 가격은 다릅니다.
다음 주에도 확인합니다.
```

### 3-2. 튜터와 해설지 역할을 동시에 해야 함

SSMK는 질문만 던지는 튜터가 아니다.

사용자는 SSMK가 참고서 해설지처럼 아래 역할도 해주기를 원한다.

- 어떤 데이터를 보고 이런 해석을 하는가?
- 어떤 현실 흐름이 숫자 뒤에 있을 수 있는가?
- 이런 경우에는 어떤 예측이나 가설을 세울 수 있는가?
- 어떤 조건이면 그 가설을 유지하는가?
- 어떤 조건이면 그 가설을 수정하는가?

### 3-3. 목차는 고정이 아니다

현재 목차를 무조건 고집할 필요는 없다.

SSMK의 소울, 미션, 비전을 강화한다면 목차와 구성은 바꿔도 된다.

권장 방향:

```text
1. 이번 주 한 줄 해석
2. 시장 온도계
3. 점수 상위 vs 가격 급등락
4. 종목 해설 카드
5. 핵심 가설
6. 배당 & ETF
7. 지난 가설 복기
8. 이번 주 공부법
9. 출처와 한계
```

## 5. 아직 남은 핵심 문제

### 문제 1. 상단 4박스가 여전히 약하다

현재 상단 박스는 구조만 생겼을 뿐, 독자에게 강한 사고 프레임을 주지 못한다.

다음 구현 방향:

- 본문 복사 금지
- 긴 문장 금지
- 말줄임표 금지
- 키워드 중심 요약
- 한 박스당 핵심 판단 1개만 표시

예시:

```text
숫자: 고점수 후보와 급등락 후보가 다름
의미: 안정 관찰과 사건 확인을 분리
레슨: 점수 순위와 가격 충격은 다른 질문
다음 확인: 급등락은 뉴스/실적/데이터 오류부터 대조
```

### 문제 2. 실제 변화 영역이 종목 나열처럼 보인다

다음 구현 방향:

- 점수 상위와 가격 급등락을 분리
- 종목별 카드/표 사용
- 가격 변화 막대 그래프 강화
- ticker/company 강조
- 긴 한 줄 나열 금지

### 문제 3. 해석이 일반론에 머문다

다음 구현 방향:

- 실제 데이터 조합에서 해석 생성
- 점수와 가격이 같은 방향인지/다른 방향인지 분석
- 1주와 4주 흐름의 차이를 해석
- ETF 흐름과 개별 종목 흐름 연결
- 뉴스/이벤트/실적 후보와 연결

### 문제 4. 초보자 레슨이 실전적이어야 한다

다음 구현 방향:

초보자에게 바로 써먹을 수 있는 관찰법을 줘야 한다.

예시:

```text
표를 볼 때 1등부터 보지 말고 두 그룹으로 나눈다.
첫째, 점수는 높은데 가격 변화가 크지 않은 종목.
둘째, 가격은 크게 움직였는데 점수 상위는 아닌 종목.
첫 번째는 꾸준히 볼 후보이고, 두 번째는 사건을 확인할 후보이다.
```

### 문제 5. 다음 확인 질문이 가설 검증형이어야 한다

다음 구현 방향:

```text
이 데이터가 A 방향이면 가설 유지.
B 방향이면 가설 수정.
```

예시:

```text
MSFT의 점수가 높지만 가격 상승이 둔하면,
시장은 이미 AI 기대를 가격에 반영했을 가능성이 있다.
다음 실적에서 Azure 성장률과 마진이 함께 개선되면
"기대가 실적으로 이어진다"는 가설을 유지한다.
반대로 AI 투자비 부담으로 마진이 눌리면
"좋은 회사지만 기대가 비싼 구간"으로 가설을 낮춘다.
```

## 6. 다음 작업 추천 순서

### 1단계. 테스트부터 강화

`tests/weekly-report-html-quality-contract.test.js`에 아래 조건을 추가한다.

- 상단 4박스에 말줄임표가 없어야 한다.
- 상단 4박스가 본문 긴 문장을 그대로 포함하면 안 된다.
- 실제 변화에 종목 3개 이상이 한 문장으로 길게 나열되면 안 된다.
- 점수 상위와 가격 급등락이 시각적으로 분리되어야 한다.
- 다음 확인 질문에 `유지`, `수정`, `낮춘다`, `대조` 같은 검증 언어가 있어야 한다.
- 해석/레슨에 추상 문장만 있으면 실패해야 한다.

### 2단계. 상단 4박스 생성 로직 수정

현재 `learningLadderHtml_`는 본문 일부를 잘라 쓰는 성격이 강하다.

다음 방향으로 바꾼다.

- `summary_signal`
- `meaning_frame`
- `practical_lesson`
- `validation_focus`

같은 별도 필드를 만들어 content block에 저장하거나, 섹션별로 별도 요약 함수를 둔다.

### 3단계. 실제 변화 렌더링 개선

긴 문장을 그대로 보여주는 대신 아래 컴포넌트로 나눈다.

- Score leaders table/card
- Price movers chart
- Data confidence/missing data note

### 4단계. 해석/레슨/다음 질문 생성 로직 개선

섹션별 템플릿을 단순 문장 반복이 아니라 데이터 조합 기반으로 바꾼다.

필요한 해석 축:

- 점수 높음 + 가격 안정
- 점수 높음 + 가격 급등
- 점수 낮음 + 가격 급등
- 점수 높음 + 가격 하락
- 1주/4주 방향 일치
- 1주/4주 방향 불일치
- ETF 흐름 확인 가능/불가능
- 뉴스 이벤트 있음/없음

### 5단계. 발행 후 자가평가 흐름 설계

새로운 평가 시트를 만들거나 기존 QA 로그에 아래 항목을 추가한다.

- 데이터 반영 점수
- 해석 깊이 점수
- 초보자 적합성 점수
- 반복 문장 위험
- 시각화 적합성
- 가설 검증 명확성
- 다음 개선 요청

## 7. 장기적으로 필요한 구조

SSMK는 발행될수록 발전하는 구조여야 한다.

장기 흐름:

```text
발행
-> 콘텐츠 품질 평가
-> 약한 섹션 기록
-> 개선 요청 생성
-> 다음 발행 로직에 반영
-> 다시 평가
```

이를 위해 나중에 아래 기능이 필요하다.

- `content_quality_reviews` 또는 기존 `qa_review_log` 확장
- 발행본별 점수 기록
- 반복 문장 탐지
- 섹션별 약점 자동 기록
- 다음 발행 전 개선 요청 자동 반영
